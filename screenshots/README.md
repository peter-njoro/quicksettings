# Screenshots

Screenshots are intentionally not generated from mockups. Before publishing a
release, capture the real widget on a live Plasma 6 session and store the
following files here:

1. `main-dark.png` — the main panel in dark appearance.
2. `main-light.png` — the main panel in light appearance.
3. `connectivity.png` — the expanded connectivity view.
4. `audio.png` — the expanded audio view.
5. `power.png` — the expanded power view.

Recommended capture command (on Plasma Wayland or X11):

```bash
spectacle -r -o screenshots/main-dark.png
```

Use a consistent panel position, accent colour and desktop wallpaper so the
listing looks coherent on KDE Store.
